Más sobre el proyecto

TiendaWeb es un sitio de demostración hecho con HTML, CSS y JavaScript, sin librerías externas. Los productos, el carrito y los registros no se guardan de manera real.

El sitio está publicado en línea con GitHub Pages. Puedes consultar el código fuente en el repositorio del equipo.
